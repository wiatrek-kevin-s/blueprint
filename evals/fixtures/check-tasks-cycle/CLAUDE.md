# Project instructions: Bakery Pricing Plan

## Intent

Write a one-page pricing plan the bakery owner can follow every month, from the agreed brief.

## Start of every session

Read `docs/progress-log.md` and `docs/tasks.json`, say in two lines where things stand, then do the next task.

## Evidence

A task is done only when its check passes and the log records what was checked.

## Context

Start a fresh chat when this one grows long, and re-read this file after any compaction.

## Saving work

Save the plan after every task; keep the previous version beside it.

## When to stop and ask

Stop and ask when the brief can be read two ways or a decision would change.

## Final review

Offer the final review in a fresh chat, from `docs/final-review.md`.
