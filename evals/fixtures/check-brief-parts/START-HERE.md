# Start here: Bakery Pricing Plan

Kit 1.0 · as of 2026-11-14 · prepared with Blueprint

This kit lets a fresh Claude write a pricing plan for a small bakery, one session per chat.

## Before you start

Your last three months of ingredient receipts, needed in session 1.

## Set up

Claude Code: this folder already holds `CLAUDE.md` and the `docs` folder. Start Claude Code here.

## First message

> Let's start. Read the progress log and the task list, tell me where things stand, and begin session 1.

## Kit files

Only these files count: `CLAUDE.md`, `docs/build-brief-1.md`, `docs/build-brief-2.md`, `docs/progress-log.md`, `docs/tasks.json` and `docs/final-review.md`.
